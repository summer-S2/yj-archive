# FA 웹 섹터 분석 화면 섹터 미제공 상품 고지 문구 추가 및 정책서 보완

## 1. 사용자 스토리

> FA로서,
> 나는 고객의 섹터 분석 화면에서 일부 상품이 섹터 분석에 포함되지 않는 이유를 바로 확인하고 싶다.
> 그래서, 재간접·피더펀드·MMF·사모펀드 등 구조적 사유로 섹터 분석에서 제외되는 상품이 있어도 고객에게 오해 없이 안내할 수 있다.

## 2. 기능 요구사항

- 종목진단 > 업종(섹터) 탭 하단에 섹터 미제공 상품 유형과 사유를 안내하는 고지 문구를 표시해야 한다.
- 고지 문구는 툴팁·팝업 등 추가 인터랙션 없이 화면에 바로 노출되어야 한다.
- 정책서(투자설계-종목진단-섹터.md)에 국내 펀드(ETF 제외) 섹터 미제공 케이스의 처리 기준을 명시해야 한다.
- 정책서에 섹터 미제공 종목의 화면 처리 방침(분석 대상 제외 + 고지)을 명시해야 한다.

## 3. 화면 문구 (FA 웹)

### 대상 화면
- **경로**: `고객 상담 > 투자설계 > 종목진단 > 업종(섹터) 탭`
- **URL**: `<화면 경로>`
- **화면 ID**: `<화면 ID>` (기존, 수정)

### Info 영역 전체 구성 (하단, 항상 표시)

기존 Info 문구 + 섹터 미제공 고지 문구를 화면 하단 Info 영역에 일괄 구성한다. 조건부 표시 없이 항상 노출한다.

| 영역 | 문구 |
|------|------|
| Info | 자산 정보를 전달 받은 일시 기준 투자 종목 및 평가 금액이므로 실제 증권사와 상이할 수 있습니다. |
| Info | 마지막 제출 시점 `{일시}` |
| Info | 일부 보유 상품은 아래 사유로 업종(섹터) 진단에서 제외될 수 있습니다. |
| Info | • 재간접·피더펀드: 모펀드 포트폴리오를 통해 간접 투자하는 구조로, 독립적인 섹터 정보가 제공되지 않습니다. |
| Info | • MMF(머니마켓펀드): 단기금융상품으로 섹터 분류가 적용되지 않습니다. |
| Info | • 사모펀드: 상품 특성상 섹터 정보를 공개하지 않는 경우가 있습니다. |

## 4. 정책서 변경 (정책서(투자설계-종목진단-섹터.md)

### 4-1. 3-3 섹션에 추가: 섹터 미제공 케이스 처리 기준

국내 펀드(ETF 제외) 중 아래 유형은 외부 데이터 제공처에서 섹터 정보가 제공되지 않으며, 섹터 미제공으로 처리한다.

| 미제공 유형 | 사유 | 처리 방식 |
|---|---|---|
| 재간접·피더펀드 | 모펀드 포트폴리오를 통해 간접 투자하는 구조로 외부 데이터 제공처가 독립 섹터를 제공하지 않음 | 섹터 미제공으로 처리 |
| MMF(머니마켓펀드) | 단기금융상품으로 섹터 분류 미적용 | 섹터 미제공으로 처리 |
| 사모펀드 | 상품 특성상 운용사가 섹터 정보를 공개하지 않는 경우가 많음 | 섹터 미제공으로 처리 |
| 운용사 미신고·소규모·운용 중단 | 외부 데이터 제공처 미수신 | 섹터 미제공으로 처리 (개선 과제) |

### 4-2. 섹터 미제공 종목의 화면 처리 방침 추가

> 섹터 정보가 없는 종목은 섹터 분석 대상에서 제외하며, 화면(종목진단 > 업종(섹터) 탭) 하단 고지 문구를 통해 미제공 사유를 안내한다.

### 4-3. 관련 이슈 목록 업데이트

정책서 frontmatter의 관련 이슈 목록에 이번 QA 이슈를 추가한다.
